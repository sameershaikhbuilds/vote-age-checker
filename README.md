# 🗳️ Vote Age Checker

A simple and beginner-friendly web application that checks whether a user is eligible to vote based on their age.

## 🚀 Demo

Enter your age and click **"Check Eligibility"** to instantly see whether you are eligible to vote.

## ✨ Features

- Check voting eligibility instantly
- Input validation
- Handles empty and invalid inputs
- Clean and responsive UI
- Beginner-friendly JavaScript project

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 💡 How It Works

1. Enter your age.
2. Click **Check Eligibility**.
3. The application will display one of the following:

- ✅ You are eligible to vote.
- ❌ You are not eligible to vote.
- ⚠️ Please enter a valid age.
